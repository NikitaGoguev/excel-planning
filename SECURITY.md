# Security Policy

## Поддерживаемые версии

Security fixes выпускаются для последней опубликованной версии QuarterPlan Excel.

## Макросы и доверие

XLSM v1.0.0 содержит неподписанный VBA-проект. Это означает, что Excel может заблокировать макросы или показать предупреждение безопасности.

- скачивайте файлы только из официального [GitHub Release](https://github.com/NikitaGoguev/excel-planning/releases/latest);
- сверяйте файл с `SHA256SUMS.txt`;
- не включайте макросы в книге, полученной по почте или из стороннего зеркала;
- при сомнении используйте no-macro XLSX и изучите VBA source в `assets/vba/`.

Проект не использует сетевые запросы, ActiveX automation, Power Query или скрытое исполнение внешних программ из workbook runtime. Windows-only developer scripts используют Excel COM для синхронизации и acceptance-проверки VBA.

## Сообщить об уязвимости

Не публикуйте потенциальную уязвимость вместе с рабочим exploit в обычном issue. Используйте private vulnerability report в разделе Security репозитория. Если эта функция недоступна, свяжитесь с владельцем через профиль GitHub и передайте минимальное описание безопасным каналом.

В сообщении укажите версию workbook, Excel/OS, затронутый макрос или лист, ожидаемое влияние и минимальные шаги воспроизведения.
