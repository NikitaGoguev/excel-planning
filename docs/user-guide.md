# Руководство пользователя QuarterPlan Excel

## Установка и проверка

1. Откройте [последний Release](https://github.com/NikitaGoguev/excel-planning/releases/latest).
2. Скачайте XLSM для полной автоматизации или XLSX для работы без макросов.
3. Сверьте SHA-256 с `SHA256SUMS.txt`.
4. На Windows при необходимости откройте свойства файла и нажмите «Разблокировать».
5. Включайте макросы только для проверенного файла из официального Release.

## Настройка команды

На `00_Настройки` укажите команду, руководителя, год, квартал и часы рабочего дня. Заполните количество людей по ролям; XLSM обновит таблицу сотрудников. Для каждого сотрудника доступны аллокация и три диапазона отпусков.

На `01_Настройки квартала` задайте начало, конец и число рабочих дней по производственному календарю. XLSM сформирует требуемое количество строк праздников.

`02_Capacity` рассчитывает capacity автоматически. Для дизайнеров используются отдельные строки количества, отпусков и серый параметр `Фокус-фактор дизайнеров` (по умолчанию 70%). Колонка переопределения предназначена для сценарного баланса и не заменяет employee-level данные scheduler.

## Оценка задач

На `03_Оценка задач` заполните приоритет, направление, описание, ключ и оценки DE/AN/BE/FE/QA.

- `>` создаёт дочернюю задачу;
- `x` удаляет ветку с выбором переноса оценок;
- `Обновить` восстанавливает действия и формулы после ручных правок;
- `Импорт CSV` читает `Ключ запроса` и `Тема` из UTF-8 comma-delimited файла;
- `Экспорт` создаёт переносимый XLSX оценок;
- строковый `Экспорт` создаёт express-estimate workbook для корневой задачи и записывает DE в существующее поле `Design` шаблона;
- `+` за таблицей открывает варианты комментария для корневой задачи.

Оценки вводятся только на листьях декомпозиции. Родительские значения рассчитываются автоматически.

## Квартальный план

1. На `04_Квартальный план` нажмите `Загрузить 03 в бэклог`.
2. Перемещайте задачи с помощью `+`, `\\`, `-`, `↑`, `↓`; `++` переносит весь backlog в план.
3. Укажите релиз, статус и комментарии.
4. Нажмите `Посчитать план`.
5. Используйте `Экспорт плана` для отдельного XLSX.

Scheduler рассчитывает активный план сверху вниз, учитывает рабочие дни, аллокации и отпуска сотрудников. DE начинается одновременно с AN (либо с первой доступной даты задачи, если AN пуст), резервирует дизайнеров между задачами, но не задаёт старт BE/FE/QA и не влияет на `Завершение (план)`. Серая зона и backlog не получают календарные даты.

## Проверка checksum в PowerShell

```powershell
Get-FileHash .\QuarterPlan-Excel-v1.0.0.xlsm -Algorithm SHA256
```

Сравните значение с соответствующей строкой в `SHA256SUMS.txt`.
